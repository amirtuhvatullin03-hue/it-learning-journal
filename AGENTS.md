# Project instructions

Global rules live in `~/.config/opencode/AGENTS.md`. This file holds only
what is specific to this project.

## Status

Репозиторий — это **Obsidian-волт** с учебным планом по переходу в IT (учёба
1–2 ч/день дома, 6–8 ч/день в колледже, только бесплатные ресурсы).
Кодовой базы нет.

## Layout

- `Home.md` — дашборд хранилища (Dataview + Tasks). Точка входа
- `obsidian-setup.md` — как открыть папку как vault, какие плагины поставить
- `Основы/Как всё работает.md` — объяснение с нуля: компьютер, память, стек/куча, сеть, DNS, HTTP, веб, ИИ, кибербез, карьера + связка всего
- `Основы/Словарик.md` — ~250 терминов плана и проектов простыми словами
- `plan/README.md` — главная дорожная карта (фазы 0–5, правила против выгорания, выбор специализации, реалистичный путь к релокации)
- `plan/college-map.md` — встраивание колледжа в план: карта дисциплин (корзины A/B/C), протоколы «домашка → GitHub» и «перемены с телефоном», критерий пересмотра решения об учёбе
- `plan/week-0-3.md` — первые 4 недели по дням
- `plan/english.md` — план английского A2–B1 → B2/C1
- `plan/setup.md` — настройка окружения на Windows (WSL2, инструменты, бесплатные облака)
- `plan/resources.md` — все бесплатные ресурсы со ссылками
- `plan/tracker.md` — журнал замеров уровня, правила трекера, чек-лист выгорания
- `Проекты/Идеи.md` — 5 идей проекта на лето 2027 + рекомендация + помесячные планы
- `Проекты/Разбор идей.md` — подробный разбор каждой идеи: механика, риски, кому это берёт, правило выбора
- `Проекты/Зачем проект.md` — зачем проект нужен в портфолио, кому он полезен как инструмент, что он даёт лично и чего не даст
- `Проекты/Зачем проект 2-5.md` — то же для остальных четырёх идей: пользователи, отличие от аналогов, личная выгода, границы, сводная таблица
- `Проекты/Идеи простыми словами.md` — пересказ всех пяти идей без жаргона + тест выбора + «проба за 2 недели»
- `Шаблоны/` — 4 шаблона: дневная заметка, недельный обзор, замер уровня, идея проекта
- `Журнал/Дневник|Недели|Замеры/` — дневные заметки, недельные обзоры, замеры уровня
- `.obsidian/` — настройки vault (app, core-plugins, community-plugins, daily-notes, templates)

## Commands

Не применимо — нет кода. Проверка целостности плана: открыть `Home.md` и сверить
с `plan/tracker.md` и `Журнал/Замеры/`.

## Conventions

- Язык документов — русский, термины и названия ресурсов оставлять на английском.
- Все рекомендации по деньгам — только бесплатные; платное помечать явно.
- Ссылка на внешний ресурс = один раз, в `plan/resources.md`. В остальных файлах
  давать только название.
- План пишется под реальный темп (1–2 ч/день дома, 5 дней в неделю) — не раздувать объём.
- **Каждая заметка имеет YAML-frontmatter** с полями `тип`, `раздел`, `статус`,
  `цель` — на этом построены запросы Dataview в `Home.md`. Новую заметку без
  frontmatter не создавать.
- Внутренние ссылки — в стиле Obsidian (`[[путь/файл]]`), не markdown-ссылки.
- Шаблоны используют синтаксис **Templater** (`{{date:YYYY-MM-DD}}`), а не
  встроенного Templates (`{{date}}`) — иначе даты не подставятся.

## Gotchas

- Ресурсы и бесплатные тарифы меняются: Oracle Always Free урезали до 2 OCPU/12 GB
  (2026), DigitalOcean убрали из GitHub Student Pack (июль 2026), fast.ai актуальная
  версия — 2022 года. Перед тем как опираться на лимит, проверять актуальную страницу.
- Трекер ведётся в Obsidian (`Журнал/`), а не в `plan/tracker.md` — тот нужен только
  для замеров уровня раз в 4 недели и чек-листа выгорания.
- Правило 20 минут в `plan/README.md` — не метафора, а критерий дня в трекере.
- Колледж занимает 6–8 ч/день. Домашние слоты (1–2 ч) нельзя отдавать ему —
  при конфликте сначала снижать нагрузку в колледже (перезачёт, свободный
  график), а не сокращать свой план.
- Решение об учёбе пересматривается по объективной метрике (доля релевантного
  времени ≥ 45%), а не по настроению. Сначала делаются дешёвые пункты
  `college-map.md` §6.1–6.3, и только потом рассматривается уход.
- **Не выполнять `Remove-Item` по фильтру, зависящему от кириллических имён
  папок.** PowerShell в этой консоли не резолвит кириллицу в литералах —
  команда удалит не те файлы. Сначала проверять выборку (`Select-Object FullName`),
  затем удалять по полному пути.
- Плагины из `.obsidian/community-plugins.json` **не установлены** автоматически:
  после первого открытия vault их нужно поставить через «Обзор» в настройках
  community-плагинов.
