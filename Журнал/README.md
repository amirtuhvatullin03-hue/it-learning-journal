# Дневник

Ежедневные заметки лежат в [[Дневник]] с именем `ГГГГ-ММ-ДД`.

**Как создавать:** иконка календаря в левой панели Obsidian → «Открыть сегодняшнюю заметку». Шаблон подставится сам (плагин Templater).

**Что заполнять (минимум):**
1. Галочка в блоке «Минимум дня» — сделал хоть 20 минут.
2. Энергия 1–5. Это важнее, чем часы: по ней видно выгорание.

**Всё остальное — по желанию.** Трекер не должен превращаться в бюрократию, иначе ты его забросишь.

Подробности: [[../obsidian-setup|Настройка Obsidian]].
