# Замеры

Замеры уровня лежат в [[Замеры]] с именем даты.

**Когда заполнять:** раз в 4 недели, плюс в день тёмной недели. Занимает 20–30 минут.

**Как создавать:** в папке [[Замеры]] → новая заметка → команда **Templater: Insert template** → шаблон «Замер уровня».

**Зачем это нужно:** без объективных цифр ты оцениваешь себя по ощущениям, а ощущения врут. Здесь четыре независимых источника правды:
- `check50` / `style50` — баллы CS50x
- TryHackMe — публичный профиль, тебя видно рекрутерам
- PortSwigger — ранг в Hall of Fame среди всех участников Академии
- доля релевантного времени в колледже — растёт ли твоя эффективность

Подробности: [[../obsidian-setup|Настройка Obsidian]].
