# Недели

Недельные обзоры лежат в [[Недели]] с именем `ГГГГ-WНН` (например, `2026-W47`).

**Когда заполнять:** воскресенье, 10–15 минут. Это единственный день, когда смотришь назад за неделю.

**Как создавать:** в папке [[Недели]] → новая заметка → команда **Templater: Insert template** → шаблон «Недельный обзор».

**Что смотреть:**
- сколько дней из 5 ты реально занимался (а не сколько минут)
- доля релевантного времени в колледже — растёт или падает
- **одна главная цель** на следующую неделю (не пять)

Подробности: [[../obsidian-setup|Настройка Obsidian]].
