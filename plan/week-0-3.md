# Первые 4 недели — детально

> **Актуальное расписание:** [[plan/fundament-3-months]] — 12 недель по датам, первые
> 4 недели по дням, выбор языка и критерии перехода. Этот файл оставлен как детализация
> недели 0 и первый черновик. Если таблицы расходятся — верь графику из `fundament-3-months`.

План рассчитан на 1–2 ч/день, 5 дней в неделю. Воскресенье — выходной.
Правило 20 минут действует всегда: сделал 20 мин — день засчитан.

## Неделя 0 — Подготовка и «разведка» (~5–7 ч)

Цель: рабочая среда, аккаунты, понимание, где ты сейчас.

| День | Что делать | Время |
|---|---|---|
| Пн | Установить VS Code, Python, Git. Создать GitHub-аккаунт. Сделать первый коммит в репозиторий `learning-log`. Записать в `tracker.md`: что уже умею, чего не умею | 60 мин |
| Вт | Подать заявку на **GitHub Student Pack** (education.github.com/pack). Параллельно: **составь карту колледжа** (`college-map.md` §8) — выпиши все дисциплины и разложи по корзинам A/B/C | 60–90 мин |
| Чт | **Тест уровня на Python** (30 мин): реши 5 задач из CS50P-задачника и посмотри, где буксуешь. Плюс Anki: создай колоду `tech-english` и заведи первые 10 карточек | 60 мин |
| Пт | CS50x — блок «C, лекция 1 + 2» (синтаксис, переменные, условия, циклы). Напиши в трекер: что было непонятно | 90 мин |
| Сб | CS50x — первые задачи по C. Поставь и запусти `check50` по инструкции с сайта курса. Разберись с `git add/commit/push` | 90–120 мин |
| Вс | Отдых | 0 |

**Что должно быть готово к концу недели 0:**
- [ ] Python запускается, VS Code работает, Git коммитит
- [ ] Заявка на Student Pack подана
- [ ] CS50x открыт, первые лекции посмотрены
- [ ] `tracker.md` заполнен
- [ ] Английский: 5 дней подряд по 20 мин (хотя бы в первый день сделано)
- [ ] **Контакты в `README.md`:** завести рабочую почту (не личную) и вписать её + Telegram. Рекрутер должен иметь способ тебе написать

## Неделя 4 — Тёмная неделя + замер

По правилу: **раз в 4 недели — тёмная неделя.** Никакого нового материала.

| День | Что |
|---|---|
| Пн–Пт | Только английский (30 мин) + повторение своих конспектов + лёгкое чтение (Computerphile / Computerphile-ролики, статьи) |
| Сб | Обновление трекера, замер прогресса, план на следующие 4 недели |
| Вс | Отдых |

**Замер накануне тёмной недели:** посчитай свои баллы в check50, открой TryHackMe/PortSwigger (если уже начал), посчитай коммиты. Запиши в `tracker.md` как baseline. Через 4 недели сравнишь.

**Пересмотр маршрута после 4 недель:**
- ≥ 70% по заданиям CS50x → идёшь дальше по плану
- 40–70% → продолжай, но добавь 1 дополнительную неделю на проблемные блоки
- < 40% → ты на верном пути, но замедлись: 2 недели на блок вместо 1, и добавь Missing Semester позже
