# Колледж: как встроить его в план

**Вводные:** IT-колледж, платный, 6–8 ч/день (~40 ч/нед), контент частично не тот, практики мало, домой доступно 1–2 ч/день. Уход пока не рассматривается.

---

## 1. Экономика решения

| Показатель | Значение |
|---|---|
| Время в колледже | ~40 ч/нед (8 ч × 5 дней), включая дорогу |
| Из них релевантных цели | ~8–10 ч/нед (теория + домашка по смежным предметам) |
| Твой домашний ресурс | 1–2 ч/день ≈ 8–10 ч/нед |
| **Суммарно** | **~50 ч/нед, релевантных ~18 ч/нед** |

Реальная проблема — не «мало времени», а **конверсия**: 32 часа в неделю уходят в дисциплины, которые не ведут к цели. Их можно либо сократить (делать на минималке), либо переиспользовать.

**Цель на 3 месяца:** релевантная доля с 25% → 45%. Это +10 ч/нед полезной работы без единого рубля и без ухода.

---

## 2. Классификация дисциплин (сделай карту)

Раздели все дисциплины колледжа на три корзины. Шаблон — внизу файла.

### Корзина A — «Твой трек» (вкладывайся максимально)
Предметы, которые прямо ведут к цели: программирование, алгоритмы и структуры данных, базы данных, сети, операционные системы, информационная безопасность, веб-разработка.

**Что делать:**
- Это твоя **основная программа**. CS50x в таком случае идёт как **систематизация и тренажёр**, а не как второй курс: закрывает то, что в колледже дают плохо (C, указатели, алгоритмы, стиль кода), и даёт автоматическую проверку (`check50`), которой в колледже нет.
- Каждую лабораторную и домашнюю работу **переводи в GitHub** (см. протокол ниже).
- Сдавай экзамены на максимуме — это твои точки отсчёта в `tracker.md`.
- Задавай вопросы на паре, доучивайся — колледж становится твоим бесплатным репетитором.

### Корзина B — «Нейтрально» (сдать на минималке, не вкладываться)
Предметы, которые не ведут к цели напрямую, но дают软 skills или нужны для диплома: базы данных на Word, офисные технологии, основы экономики/менеджмента, история профессии, физкультура, иностранный язык (если он английский — это наоборот плюс).

**Что делать:**
- Сдавай на «хорошо» и забудь. Не перечитывай методички, не делай рефераты ради оценки.
- Физкультура — не трать время на отчётность; иди в зал/на улицу. Это часть твоего анти-выгорания (см. `README.md`, раздел 3, п. 6).
- Иностранный язык, если это английский — **переведи его в свою программу**: это готовый слот для английского.

### Корзина C — «Шум» (минимум усилий, максимум выживания)
Предметы, которые тебе не нужны и вряд пригодятся: 1С, MS Office, веб-дизайн/фотошоп, бухучёт, «информационная безопасность по учебнику», основы бухучёта, дисциплины по «профориентации».

**Что делать:**
- Сдай на минималке (удовлетворительно) и **не трать на них ни минуты сверх необходимого**.
- Если есть возможность перезачесть/заменить дисциплину — обсуди с куратором, это самый дешёвый способ выиграть 4–6 ч/нед.

## 3. Протокол «Домашка колледжа → артефакт в портфолио»

Это конвертирует бесполезную практику в полезную. Работает для корзин A и B.

**Шаги (10 минут дополнительной работы к обычной домашке):**
1. Решаешь задание как обычно → получаешь рабочий код.
2. Кладёшь в отдельный репозиторий GitHub: `college/<предмет>-<тема>`.
3. README на **английском**: что делает, как запустить, какие концепции использовал.
4. Коммиты с осмысленными сообщениями на английском.
5. Раз в 2–3 недели — скриншот/график (ER-диаграмма, дамп запроса, вывод тестов).

**Что это даёт:**
- Домашка перестаёт быть «для оценки» и становится артефактом.
- Английский практикуется автоматически, без отдельного слота времени.
- На собеседовании: «вот что я делал в колледже» → готовые кейсы.
- Ноль дополнительных часов: та же работа, другое оформление.

**Важно:** не выкладывай то, что тебе не принадлежит, и не делай чужие задания за деньги. Это твои собственные учебные проекты.

## 4. Протокол «Перемены» (5–10 минут × 5 = 30–50 мин/нед)

У тебя 6–8 ч в колледже. Это 5–10 минут на каждой перемене + дорога. **Это время, которое уже есть, и которое сейчас, скорее всего, уходит в телефон.**

Что делать с телефона (всё работает в браузере или по SSH, установка не нужна):

| Что | Время | Что даёт |
|---|---|---|
| **TryHackMe** (браузер, AttackBox) | 5–10 мин | Реальные лабы по сетям/Linux/вебу |
| **picoCTF** | 5–10 мин | Задачи по ИБ, разноуровневые |
| **OverTheWire: Bandit** | 5–10 мин | SSH + Linux-команды, тренировка рук |
| **Anki** (повторение) | 5 мин | Английский, без перерыва в ритме |
| **English with Lucy / Computerphile** (YouTube) | 5–10 мин | Английский на слух, без отдельного слота |
| **Чтение RFC / MDN** на телефоне | 5–10 мин | Технический английский |

**Правило:** одна привычка за раз. Начни с **Anki (5 мин) + TryHackMe (10 мин)** и доведи до автоматизма за 2 недели. Остальное добавляй позже.

**Лайфхак с дорогой:** в дороге и на перемене слушай **подкасты на английском** (Computerphile, 6 Minute English) — аудио не требует экрана. В наушниках.

## 5. Как перестроить домашние 1–2 ч

Старый режим (как в CS50x по умолчанию): «лекция → задачи».
Новый режим (эффективнее, когда теории и так хватает в колледже): **«задачи → теория по мере надобности»**.

**Правило: сначала делаешь, потом читаешь.**
1. 10 мин: пробуешь решить задачу без подсказки.
2. Застрял → читаешь только нужный кусок лекции/доки.
3. Решаешь.
4. 10 мин в конце: записываешь в конспект 3 вещи, которые понял, и 1 вопрос.

**Что это даёт:** практика в 4–5 раз больше на ту же минуту. Именно этого не хватает в колледже.

**Распределение домашнего времени (1–2 ч/день):**

| День | Что | Мин |
|---|---|---|
| Пн | CS50x: задачи (теория — только если застрял) | 60–90 |
| Вт | CS50x: задачи | 60–90 |
| Ср | CS50x: задачи | 60–90 |
| Чт | Побочный трек: Missing Semester / TryHackMe / PortSwigger | 45–60 |
| Пт | Побочный трек + Git-коммит недельных артефактов | 45–60 |
| Сб | Большая сессия: проект / лабы / CS50x | 90–180 |
| Вс | Отдых | 0 |

**Английский больше НЕ отдельный слот** — он встроен: английские лекции CS50x + англоязычные README и коммиты + Anki по 5 мин. Отдельный 20-минутный ритуал на английский оставь только как «минимальный день» (закончил 20 мин — день засчитан).

## 6. Про «платный колледж» — честный разбор

Ты платишь за ~1600 часов в год. Посчитай:

- **Если релевантной доли 25%** → ты платишь за ~400 часов полезного обучения. Остальное — впустую.
- **При доле 45%** → ~720 часов. Уже ощутимо.
- **При доле 60%+** → колледж перестаёт быть проблемой.

**Правило принятия решения (объективное, не по настроению):**

> Через **3 месяца** от начала работы по этому протоколу посчитай в `tracker.md`: сколько часов колледжа дали релевантные навыки (корзина A) и сколько — навыки, конвертируемые в портфолио (протокол §3). Если релевантная доля **< 25%** — это объективное основание для перевода на другую специальность/колледж или ухода, а не каприз.

**Порядок действий, если доля низкая** (от дешёвого к дорогому):
1. Заменить/перезачесть шумовые дисциплины у куратора. Бесплатно.
2. Взять уменьшенную нагрузку / свободный график, сдать экзамены раньше. Бесплатно или дёшево.
3. Перевестись на смежную специальность (например, из «Информационные технологии» в «Программное обеспечение» или «Информационная безопасность»). Обычно перевод внутри колледжа = смена части дисциплин, а не с нуля.
4. Уйти. Последний вариант: это потеря диплома + 3 месяца на перестройку + риск выгорания.

Обрати внимание: **пункты 1–3 дают большую часть выигрыша и не стоят ничего.** Поэтому менять решение об учёбе имеет смысл только после того, как сделаны 1–3.

## 7. Что попросить у колледжа (сделай в первую неделю)

- [ ] Список дисциплин и преподавателей — чтобы заполнить карту ниже
- [ ] Есть ли в программе дисциплины по: сетям, ОС, БД, ИБ, вебу, Linux, алгоритмам? В каких семестрах? (чтобы понять, что будет дальше и когда готовиться)
- [ ] Можно ли перезачесть/заменить дисциплину без смены специальности
- [ ] Есть ли свободный график / заочная форма / уменьшенная нагрузка
- [ ] Есть ли доступ к лабораториям (Linux-серверы, сеть, Kali, SIEM-стенд) — для практики
- [ ] Можно ли получить доступ к серверам/сети колледжа для лабораторных и проектов
- [ ] Есть ли кружки/секции по кибербезу, CTF-команды, Linux-клуб — **это самый дешёвый способ получить практику и единомышленников**
- [ ] Преподаватели, которые дают практику — к ним можно ходить за дополнительными задачами

```markdown
| 1 | | | | | | |
| 2 | | | | | | |
| 3 | | | | | | |
| 4 | | | | | | |
| 5 | | | | | | |
| 6 | | | | | | |
| 7 | | | | | | |
| 8 | | | | | | |

**Итого:**
- Всего ч/нед в колледже: __
- Корзина A (вкладываюсь): __ ч/нед
- Корзина B (на минималке): __ ч/нед
- Корзина C (шум, минимум): __ ч/нед
- Доля релевантного (A + B×0.5): __ %
- Домашних ч/нед: __
- Суммарно релевантных: __ ч/нед
```

**Цель: через 3 месяца доля релевантного ≥ 45%.**
