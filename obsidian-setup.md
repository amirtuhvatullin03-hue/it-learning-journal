# Настройка Obsidian (20 минут)

Этот репозиторий уже подготовлен как **vault** (хранилище) Obsidian: лежат `.obsidian/`, шаблоны, папки журнала и дашборд `Home.md`.

---

## 1. Почему Obsidian, а не Notion

Коротко: Notion — облако и красивая база данных; Obsidian — **файлы на твоём диске** + надстройка. Для программиста разница принципиальная.

| | Obsidian | Notion |
|---|---|---|
| Данные | Файлы `.md` у тебя на диске | На серверах Notion |
| Git | Работает нативно (плагин Obsidian Git) | Нет |
| Офлайн | Полный | Ограниченно |
| Автоматизация | Любой скрипт, Obsidian CLI, парсеры | Только через API |
| Учётные записи | Не нужны | Нужны, экспорт ограничен |
| Цена | Бесплатно для личного использования | Бесплатно с лимитами |
| Мобильный | Приложение платное (~$9) | Бесплатно |

**Ключевое:** твои заметки = обычные markdown-файлы = то же, что ты и так будешь писать в Git. Это не отдельный «кошелёк» с контентом, который потом надо экспортировать.

**Когда выбрать Notion:** если ты вообще не хочешь возиться с папками и плагинами и тебе важнее мобильность и «просто работает». Тогда импортируй эти markdown-файлы (`Файл → Импорт → Markdown`) и повтори схему журнала на базах Notion. Но автоматизации и git там не будет.

## 2. Установка

1. Скачай Obsidian: `obsidian.md` → **Download** (бесплатно, без аккаунта для личного использования).
2. Установи и запусти.
3. **Файл → Открыть папку как хранилище** → выбери корень этого репозитория (папку, где лежит `Home.md` и `.obsidian`).
4. Obsidian спросит про безопасность → выбери «Доверять автору».
5. Слева в панели файлов появится дерево: `Home.md`, `plan/`, `Проекты/`, `Шаблоны/`, `Журнал/`.
6. Открой `Home.md` — это твой дашборд.

## 3. Плагины (это и есть «система», а не просто заметки)

**Настройки → Сторонние плагины** → выключи «Ограниченный режим» → **Обзор** → установи:

| Плагин | Зачем |
|---|---|
| **Dataview** | Дашборды: собирает данные из твоих заметок в таблицы. Без него `Home.md` — просто текст |
| **Tasks** | Все задачи (`- [ ]`) со всех страниц в одном списке, с дедлайнами |
| **Templater** | Шаблоны с автоподстановкой дат (`{{date:YYYY-MM-DD}}`, `{{date:GGGG-[W]WW}}`) |
| **Calendar** | Календарь в боковой панели — по нему открываешь дневные заметки |
| **Obsidian Git** | Автосинхронизация заметок с GitHub. История версий твоего обучения |
| **Spaced Repetition** | Карточки прямо в Obsidian (если решишь не заводить Anki отдельно) |
| **QuickAdd** | Быстрые макросы: «создать дневную заметку», «добавить в бакет» |
| **Excalidraw** | Схемы от руки (сетевые диаграммы, архитектура проекта) |
| **Homepage** | Открывать `Home.md` при запуске |

## 4. Настройка плагинов

### Templater (обязательно)
- Настройки → Templater → **Template folder location** → `Шаблоны`
- Включи **Trigger Templater on new file creation**
- Создай шаблон `Шаблоны/Дневная заметка.md` — он уже создан, просто проверь путь

### Daily Notes (встроенный)
Уже настроен: папка `Журнал/Дневник`, формат `YYYY-MM-DD`, шаблон `Шаблоны/Дневная заметка`.
Открыть дневную заметку: иконка календаря на панели → «Открыть сегодняшнюю заметку».

### Obsidian Git
- Настройки → Obsidian Git → включи **Auto commit interval** (10 мин) и **pull on startup**
- Настройки уже лежат в репозитории: `.obsidian/plugins/obsidian-git/data.json`
- Репозиторий: **https://github.com/amirtuhvatullin03-hue/it-learning-journal**
- Токен для пушей: `gh auth setup-git` уже выполнен, git знает твой аккаунт
- Убедись, что в репозитории настроен `user.name` и `user.email` в Git
- Это даст тебе историю обучения в GitHub — отдельный, но приятный бонус

> **Первый пуш уже сделан.** После открытия vault нажми в плагине Obsidian Git кнопку **Pull**, чтобы подтянуть изменения с GitHub, и всё заработает автоматически.

### Dataview
Устанавливается и работает сразу. Индекс обновляется сам.
Если таблицы в `Home.md` пустые — проверь, что в заметках `plan/*.md` есть frontmatter с полями `раздел`, `статус`, `цель` (они уже проставлены).

## 5. Как этим пользоваться каждый день

### Ежедневно (2 минуты)
1. Иконка календаря → **Открыть сегодняшнюю заметку**.
2. Заполни: что делал, минуты, энергия 1–5.
3. Поставь галочку «20 минут» в блоке «Минимум дня».

Готово. Больше ничего не нужно — не превращай это в бюрократию.

### Еженедельно (15 минут, воскресенье)
1. Создай заметку в `Журнал/Недели/` с именем `2026-W48` (ГОД-неделя).
2. Через команду **Templater: Insert template** вставь `Шаблоны/Недельный обзор`.
3. Заполни таблицу дней, строку «Колледж: ч / релевантных», «Английский: дней / 5».
4. Одну главную цель на следующую неделю.

### Раз в 4 недели (30 минут)
1. Создай заметку в `Журнал/Замеры/` с именем даты.
2. Вставь шаблон `Шаблоны/Замер уровня`.
3. Заполни цифры: check50, TryHackMe, PortSwigger, доля релевантного времени в колледже.
4. **Это твой ответ на вопрос «на каком я уровне».** Без него ты полагаешься на ощущения, а ощущения врут.

## 6. Телефон

Obsidian Mobile платный (разовая покупка). Бесплатные альтернативы:

| Вариант | Что работает | Сложность |
|---|---|---|
| **AnkiDroid** (Android) + AnkiWeb | Карточки английского — самое важное с телефона | Просто |
| **Telegram-бот / чат с самим собой** | Быстрая пометка «сделал 20 мин», «застрял на X» | Просто |
| **Syncthing** (Android/Linux) | Синхронизация папки `Журнал/` без облака | Средне |
| **Working Copy + iCloud** (iOS) | Git-клиент с iCloud-синком | Средне |
| **Obsidian Mobile** | Полный доступ, платно ~$9 | — |

**Мой совет:** на телефоне оставь только **AnkiDroid** (английский) и **Telegram-заметки** (быстрые пометки). Всё остальное — на компьютере. Не пытайся вести полный трекер с телефона: это превращает учёбу в администрирование.

## 7. Структура хранилища

```
├── Home.md                 ← дашборд (открывай сюда)

│   └── Идеи.md             ← 5 идей проекта на лето

│   ├── Дневник/            ← ежедневные заметки (YYYY-MM-DD)
│   ├── Недели/             ← недельные обзоры (2026-W48)
│   └── Замеры/             ← замеры уровня раз в 4 недели
├── Шаблоны/                ← 4 шаблона
└── .obsidian/              ← настройки
```

## 8. Если что-то не работает

| Проблема | Решение |
|---|---|
| Таблицы в `Home.md` пустые | Не установлен Dataview, или нет frontmatter в заметках `plan/` |
| Даты не подставляются | Не установлен Templater или не настроена папка шаблонов на `Шаблоны` |
| Плагин не находится в обзоре | Обзор магазина community-плагинов требует интернета; проверь подключение |
| `[[plan/README]]` не открывается | Obsidian не различает файлы с одинаковым именем в разных папках — используй полный путь `[[plan/README]]`, как в дашборде |
| Кнопка «Открыть папку как хранилище» не найдена | Ты открыл файл, а не приложение: закрой окно и открой Obsidian с рабочего стола |
