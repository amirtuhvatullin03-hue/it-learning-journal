## Программирование

**Алгоритм** — пошаговая инструкция решения задачи. «Чтобы найти максимум в списке: сохрани первое значение в переменную, перебери остальные, если встретишь больше — замени». Программирование = записать алгоритм так, чтобы машина выполнила его без вопросов.

**Переменная** — именованная ячейка для значения. `age = 20`. Компьютер помнит только номер ячейки, не имя.

**Тип данных** — что можно положить в переменную и как с этим работать. `int` (целое), `float` (дробное), `char` (один символ), `bool` (да/нет), `string` (строка). Тип определяет, какие операции доступны и сколько памяти занимает значение.

**Указатель** — переменная, в которой лежит **адрес** другой переменной. Не значение, а «где лежит». Нужен, чтобы не копировать большие данные и чтобы руками управлять памятью.

**Массив** — ряд ячеек подряд в памяти. Значения одного типа. Нумерация с нуля.

**Строка** — массив символов с завершающим нулём. В C нет отдельного типа «строка» — есть массив `char` и набор функций (`strlen`, `strcmp`).

**Структура данных** — способ организовать данные. Массив (быстрый доступ по номеру, медленная вставка), связный список (быстрая вставка, медленный доступ), стек (последний пришёл — первый ушёл), очередь (первый пришёл — первый ушёл), хеш-таблица (поиск по ключу за O(1)), дерево (упорядоченный поиск).

**Big O (сложность)** — как растёт время работы при росте данных. O(1) — мгновенно, O(n) — линейно, O(n²) — квадратично. `list.append` = O(1), `list.insert(0, x)` = O(n).

**Рекурсия** — функция вызывает сама себя. Нужна база (условие выхода) и рекурсивный вызов с приближением к ней.

**Указатель на функцию / callback** — передача функции как значения, чтобы вызвать её позже.

**Утечка памяти** — выделенная память не возвращена. Программа съедает RAM постепенно.

**Segfault (segfault)** — программа полезла в память, которая не её. Обычно из-за ошибки с указателями.

**Дебаг (отладка)** — поиск причины, почему код делает не то. Инструменты: `print`, `pdb` (пошагово), `gdb`.

**Рефакторинг** — изменение структуры кода без изменения поведения. «Чищу, чтобы было легче читать, функционально то же».

**Статический анализ / линтер** — программа, которая читает твой код и ищет подозрительные места (неиспользуемые переменные, ошибки стиля). В C это `style50` из CS50x.

**Юнит-тест** — маленький тест одной функции: «дай `add(2,3)` → ожидаю 5».

**Библиотека** — готовый код, который ты подключаешь (`import` / `#include`). Не писать своё, а взять готовое.

**Фреймворк** — библиотека, которая задаёт структуру всего приложения (Flask, Django, FastAPI).

**API библиотеки** — набор функций, которые библиотека предоставляет наружу.

**IDE** — программа для написания кода с подсветкой, автодополнением, отладчиком. VS Code, PyCharm.

**Терминал (консоль)** — окно, где ты вводишь текстовые команды. Это главный рабочий инструмент в IT, а не «штука для хакеров».

**Shell (оболочка)** — программа внутри терминала, которая читает твои команды и запускает программы. Самая популярная — bash.

**CLI-аргументы** — дополнительные параметры после имени программы: `ls -la`, `git commit -m "текст"`.

**Пайп `|`** — передача вывода одной команды на вход другой. `cat file | grep "error" | wc -l` — посчитать строки со словом error.

**Перенаправление `>` и `>>`** — записать вывод в файл (>) или дописать (>>).

**Регулярное выражение (regex)** — шаблон для поиска текста. `\d+` — одна или больше цифр.

**SSH** — защищённый удалённый доступ к другому компьютеру. Основа «работаешь с любого сервера».

**Docker-образ / контейнер** — см. [[Основы/Как всё работает#Часть 5. Данные и серверы]]

## Linux и терминал

**Дистрибутив** — сборка Linux с инструментами. Ubuntu, Debian, Fedora, Arch.

**Ядро (kernel)** — ядро Linux: управляет процессорами, памятью, файлами, сетью.

**Root / sudo** — root = администратор, может делать что угодно. `sudo` = «выполни с правами администратора».

**chmod** — задать права файла: читать (`r`), писать (`w`), выполнять (`x`).

**Процесс** — работающая программа. У каждого есть PID.

**Демон / сервис** — программа, работающая в фоне постоянно (nginx, sshd, postgresql).

**systemd** — менеджер сервисов в современном Linux. `systemctl start nginx`.

**cron** — планировщик: «выполняй эту команду каждый час в 3:00».

**apt / yum** — менеджер пакетов: `sudo apt install nmap`.

**Man-страницы** — встроенная документация: `man ls`.

**tmux/screen** — терминальные мультиплексоры: несколько вкладок в одном окне, сессия не умирает при потере SSH.

**Commit** — зафиксированное изменение с сообщением.

**Ветка (branch)** — параллельная линия разработки.

**Merge / rebase** — влить ветку в другую / переложить свою ветку поверх свежей.

## Сети и интернет

Все термины подробно — в [[Основы/Как всё работает#Часть 2. Сеть]] и [[Основы/Как всё работает#Часть 3. Интернет]].

**IP-адрес** — адрес компьютера в сети.

**Порт** — номер программы-получателя внутри компьютера.

**MAC-адрес** — аппаратный адрес сетевой карты внутри одной сети.

**Подсеть / subnet mask** — «какая часть адреса — сеть, какая — конкретный компьютер».

**CIDR** — запись подсети в виде `192.168.1.0/24`.

**Шлюз / gateway** — «выход» из твоей сети наружу (обычно IP роутера).

**DHCP** — кто выдаёт IP-адреса устройствам автоматически.

**ARP** — «какому MAC-адресу соответствует этот IP в моей сети».

**NAT** — трансляция внутренних адресов в один внешний.

**TCP / UDP** — надёжный (с рукопожатием) и быстрый (без) способы передачи.

**Рукопожатие (handshake)** — установка соединения: SYN → SYN-ACK → ACK.

**TLS/SSL** — шифрование соединения + сертификат, подтверждающий, с кем ты говоришь.

**Сертификат / CA** — документ, подтверждающий, что домен принадлежит владельцу. CA — центр, который его выдаёт.

**HTTP / HTTPS** — протокол запроса-ответа для веба.

**Заголовок (header)** — метаданные в HTTP-запросе или ответе.

**Cookie / сессия** — идентификатор, чтобы сервер помнил тебя между запросами.

**DNS** — превращает имя в IP-адрес.

**BGP** — протокол, по которому сети договариваются о маршрутах.

**ASN** — номер автономной системы (сети). Например, AS15169 — Google.

**Маршрут / routing** — путь трафика.

**Route hijack / route leak** — перехват или случайная утечка маршрута; признак сетевой атаки или ошибки.

**Anycast** — один IP на много серверов, трафик идёт к ближайшему.

**CDN** — сеть серверов с копиями сайта по миру.

**Ping / traceroute / dig / nslookup** — диагностические команды: «жив ли хост», «какой путь», «какой IP у имени».

**Wireshark / tcpdump** — захват и разбор пакетов.

**Metasploit / Nmap / Burp** — инструменты: фреймворк эксплуатации, сканер портов, перехватчик HTTP.

**RIPE Atlas** — сеть бесплатных виртуальных зондов по миру для измерений.

**CT logs / crt.sh** — публичные журналы выдачи TLS-сертификатов: по ним видно все поддомены домена.

**Whois** — кто владеет доменом/IP, когда зарегистрирован.

**Ping-pong (RTT)** — см. RTT.

## Веб и API

**HTML / CSS / JS** — структура / внешний вид / поведение страницы.

**Фреймворк фронтенда** — React, Vue, Angular.

**REST API** — набор адресов и методов для работы с данными программно.

**JSON** — текстовый формат данных (объекты/массивы).

**CRUD** — Create, Read, Update, Delete: четыре базовых действия над данными.

**Статус-коды HTTP** — 200 ок, 3xx перенаправление, 4xx ошибка клиента, 5xx ошибка сервера.

**CORS** — правило, по которому браузер разрешает запросы с другого домена.

**CSRF** — атака, заставляющая браузер отправить чужой авторизованный запрос.

**XSS** — внедрение своего кода в страницу, чтобы украсть данные пользователя.

**SQL-инъекция** — подстановка SQL-кода через поле ввода, чтобы прочитать/изменить чужое.

**SSRF** — заставить сервер запросить внутренний адрес (обойти firewall).

**JWT** — подписанный токен, внутри которого лежат данные о пользователе (например, «роль: админ»).

**OAuth / OpenID Connect** — «вход через Google/GitHub» и выдача приложению доступа без передачи пароля.

**CORS preflight** — браузер спрашивает сервер: «можно ли?» перед «опасным» запросом.

**Localhost** — «сам компьютер». `127.0.0.1` — адрес, по которому ты обращаешься к себе.

## Данные и базы

**База данных** — хранилище с быстрым поиском.

**Таблица / строка / столбец** — база / запись / поле.

**Нормализация** — правила, чтобы не хранить одно и то же в десяти местах.

**Индекс** — «указатель», ускоряющий поиск (как оглавление в книге).

**Транзакция** — группа операций, которая либо выполняется целиком, либо никак. Нужна, чтобы деньги не пропадали посреди операции.

**ACID** — правила хорошей транзакции: Atomicity, Consistency, Isolation, Durability.

**SQL / SELECT / JOIN** — язык запросов / выборка / объединение таблиц по общему полю.

**ORM** — библиотека, которая пишет SQL за тебя (SQLAlchemy, Django ORM).

**NoSQL** — базы без жёсткой структуры (MongoDB, Redis).

**Дашборд** — страница с графиками и показателями.

**ETL** — Extract, Transform, Load: забрать данные, привести к виду, загрузить.

**Временной ряд (time series)** — данные с привязкой ко времени. Задержка сети по времени — временной ряд.

**Агрегация** — свёртка данных: среднее, медиана, максимум, p99.

**Медиана / p99** — «середина» / «значение, ниже которого 99% замеров».

**Энтропия** — насколько данные случайны. DNS-поддомены типа `a8f3c2b1.example.com` — высокая энтропия (туннель), `www.example.com` — низкая (нормально).

**Датасет** — набор примеров для обучения или проверки.

**Признаки (features)** — входные числа для модели.

**Метки (labels)** — правильные ответы в обучающей выборке.

**Train / test split** — делим данные: на одной части учим, на другой проверяем, что модель не выучила примеры, а нашла закономерность.

## Облако и деплой

**Виртуальная машина (VM)** — эмуляция целого компьютера с ОС.

**Контейнер / Docker** — изолированное окружение для процесса, дешёвое в сравнении с VM.

**Docker Compose** — файл, описывающий несколько контейнеров, запускаемых вместе.

**Облако** — аренда чужих серверов. **IaaS** — арендуешь виртуалку и настраиваешь сам. **PaaS** — платформа сама делает часть работы.

**Managed-сервис** — облачный сервис, настроенный за тебя (Managed Postgres, S3).

**Регион / зона** — географическое расположение облака. Always Free обычно только в «домашнем» регионе.

**VPS** — виртуальный сервер с постоянным IP.

**Инстанс** — конкретный запущенный сервер в облаке.

**Публичный IP / приватный IP** — доступен из интернета / только внутри сети.

**Egress / исходящий трафик** — трафик наружу. У многих бесплатных тарифов есть лимит или платный исходящий.

**CDN в облаке** — см. CDN.

**Скриншот/дамп** — здесь: дамп трафика (PCAP).

**Always Free / Free Tier** — бесплатный постоянный (или временный) ресурс у облачного провайдера.

**Кредиты** — бесплатные деньги на счёт облака.

## DevOps

**CI/CD** — автоматическая проверка и выкладка.

**Pipeline** — цепочка шагов: сборка → тесты → выкладка.

**Оркестратор** — система, управляющая контейнерами (Kubernetes).

**Kubernetes (k8s)** — стандарт для запуска контейнеров в проде. Сложный, поэтому для обучения — k3s или minikube.

**Terraform / IaC** — описание инфраструктуры кодом, а не кликами в консоли.

**Observability** — наблюдаемость: логи, метрики, трассировки.

**Prometheus / Grafana** — сбор метрик + графики.

**Логи / метрики / трейсы** — что произошло / как меняются числа / путь запроса по системе.

**Health check** — проверка, что сервис жив.

**Rollback** — откат на предыдущую версию.

**Ручной деплой vs автоматический** — руками на сервере или через CI/CD.

## ИИ и машинное обучение

Подробно — [[Основы/Как всё работает#Часть 7. Искусственный интеллект]].

**Модель** — обученная функция, которая принимает числа и выдаёт числа.

**Обучение (training)** — подбор параметров модели по примерам.

**Инференс (inference)** — использование обученной модели.

**Классификация** — «к какому классу относится этот объект» (атака или нет, спам или нет).

**Кластеризация** — «раздели данные на похожие группы без заранее заданных классов».

**Регрессия** — предсказание числа (сколько будет трафика, какая задержка).

**Переобучение (overfitting)** — модель выучила примеры, а не закономерность.

**Признаки / признаковое пространство** — входные данные модели.

**Датасет** — набор примеров.

**Label / метка** — правильный ответ в примере.

**Эпоха / батч / learning rate** — проход по данным / порция примеров за шаг / насколько сильно менять параметры.

**Трансформер / attention** — архитектура нейросети, на которой построены все современные LLM. Суть: при обработке каждого слова модель «взвешивает» все остальные слова в контексте.

**Токен** — кусочек текста, который модель обрабатывает. Примерно слово или часть слова.

**Контекстное окно** — сколько токенов модель держит «в голове» одновременно.

**Эмбеддинг (embedding)** — вектор чисел, кодирующий смысл. Близкие смыслы → близкие векторы. Основа поиска по смыслу и RAG.

**Fine-tuning** — дообучение модели на своих данных.

**LoRA / quantization** — способы дообучать и хранить большие модели дёшево (лёгкие «добавки» к весам и сжатие весов).

**LLM** — большая языковая модель.

**Prompt** — текст-инструкция модели.

**System prompt** — «инструкция для модели, задающая роль и правила». Обычно скрыта от пользователя, но её можно попытаться вытащить.

**Prompt injection** — попытка заставить модель выполнить инструкцию, которую она не должна выполнять.

**Indirect prompt injection** — инструкция спрятана в контенте, который модель сама читает (страница, документ, письмо).

**Jailbreak** — обход ограничений модели «разговорными» приёмами.

**RAG** — поиск + генерация: сначала найти релевантное в своей базе, потом подложить в запрос модели.

**Агент** — LLM, которая сама вызывает инструменты (поиск, код, API) и делает несколько шагов.

**Excessive agency** — агент имеет больше прав, чем нужно.

**Галлюцинация** — правдоподобный, но неверный ответ модели.

**Guardrails** — ограничители вокруг модели (фильтры ввода/вывода, запрещённые темы).

**Оценка (evaluation)** — насколько модель хорошо решает задачу. Без оценки любая ML-работа — гадание.

**MCP (Model Context Protocol)** — стандартный способ подключать к LLM внешние инструменты и данные.

**Ollama** — локальный запуск open-source моделей, без облака и API-ключей.

**GPU / VRAM** — процессор для параллельных вычислений; память видеокарты.

**Квантизация** — сжатие весов модели (меньше памяти, быстрее, чуть хуже качество).

## Кибербезопасность

**Уязвимость / эксплойт / CVE / патч** — см. [[Основы/Как всё работает#Часть 8. Кибербезопасность]].

**Bug bounty** — платная программа поиска уязвимостей у компаний.

**CTF** — соревнование по решению задач по безопасности.

**Honeypot** — ловушка для атакующего.

**IDS / IPS** — обнаружение / предотвращение вторжений.

**SIEM** — сбор и корреляция логов из разных источников.

**MITRE ATT&CK** — база техник и тактик злоумышленников.

**OWASP Top 10** — топ-10 веб-уязвимостей.

**CWE** — общая классификация слабых мест (например, CWE-79 — SQL-инъекция).

**Аутентификация / авторизация** — «кто ты» / «что тебе можно».

**MFA / 2FA** — второй фактор (код из телефона).

**Принцип наименьших привилегий** — дай минимально нужные права.

**Защита в глубину** — несколько слоёв защиты, чтобы пробитие одного не было фатальным.

**Криптография / хеш / соль / ключ** — шифрование / необратимый отпечаток / случайная примесь к паролю / секрет для расшифровки.

**AES / RSA** — симметричное (один ключ) и асимметричное (пара ключей) шифрование.

**Reverse engineering (реверс)** — восстановление логики из готовой программы.

**Ghidra** — бесплатный инструмент для реверса.

**Фаззинг (fuzzing)** — подача случайных данных в программу в поисках падений.

**Статический/динамический анализ** — разбор кода / разбор поведения программы во время работы.

## Обучение и английский

**CEFR (A1–C1)** — международная шкала уровня языка: A1 — начинающий, B1 — базовый, B2 — самостоятельный, C1 — уверенный профессиональный.

**Anki** — программа для запоминания через интервальные повторения.

**Интервальные повторения** — повторять слово перед тем, как забудешь, с нарастающими интервалами.

**LingQ / Language Reactor** — инструменты для чтения и видео с двойными субтитрами.

**Подкаст / скрипт (transcript)** — аудио / текстовая расшифровка.

**Passive vocabulary / active vocabulary** — слова, которые узнаёшь / которые сам используешь.

**Shadowning (повторение за носителем)** — слушаешь и повторяешь вслух, копируя интонацию и структуру.

**Code review (ревью)** — разбор чужого кода с целью улучшения.

**Ретроспектива** — разбор, что прошло хорошо, а что нет, чтобы улучшить процесс.
